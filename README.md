## Featured Projects

### ⚡ ElectroShop

**Enterprise e-commerce backend for electronics retail — currently in active development.**

I designed the backend around **Clean Architecture, CQRS, and Vertical Slice Architecture**, with business logic separated from infrastructure concerns.

Some of the work I'm most proud of:

* Separate **Domain, Application, and Infrastructure test projects**, with isolated domain tests and integration-oriented infrastructure coverage.
* **Hybrid caching with explicit invalidation** when underlying data changes.
* Inventory and checkout workflows designed with **concurrent operations and overselling prevention** in mind.
* Secure authentication using **JWT, refresh sessions, HttpOnly cookies, roles, and policies**.
* **GitHub Actions** workflows for automated build and test verification.
* Infrastructure abstractions for storage and external services, including **Azure Blob Storage** for production-oriented deployment.

**[Backend Repository](https://github.com/Darkness00132/EcommerceApi)** · **[Angular Frontend](https://github.com/Darkness00132/ecommerce-ui)**

### 🏠 Aqark

**Arabic real-estate marketplace for brokers and property owners.**

Built as a full-stack application using **ASP.NET Core Web API, PostgreSQL, and Next.js**.

Highlights:

* Built a **multi-criteria property filtering system** covering location, property type, listing type, price, rooms, bathrooms, space, and sorting.
* Implemented **SEO-friendly slug-based property URLs** instead of database IDs.
* Built **credit-based advertisement workflows** with transactional handling.
* Added **JWT authentication, refresh tokens, Google OAuth, and role-based authorization**.
* Implemented property images, broker profiles, reviews, pagination, and an Arabic RTL interface.
* **Paymob payment integration — in progress.**

**[Backend](https://github.com/Darkness00132/AqarkV2_Backend)** · **[Frontend](https://github.com/Darkness00132/AqarkV2-frontend)** · **[Live Demo](https://aqark.vercel.app)**
